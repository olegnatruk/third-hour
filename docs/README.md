# Third Hour Documentation

This folder is the project’s shared memory. Keep it useful for both founders and any AI agent joining later.

## Start here

- [Product overview](PRODUCT.md) — what Third Hour is building and why.
- [Working context](CONTEXT.md) — current status, open questions, and next actions.
- [Decision log](DECISIONS.md) — decisions that should not be rediscovered each session.
- [Loyalty-card backend blueprint](BACKEND.md) — roles, data boundaries, QR scanning, and backend invariants.

## Documentation principles

- Prefer short, clear notes over exhaustive transcripts.
- Date decisions and context updates.
- Mark assumptions clearly until they are confirmed.
- Remove or correct information that is no longer true.
